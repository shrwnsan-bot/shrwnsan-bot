# Shrwnsan Automation

Machine account for pipeline automation — scheduled scans, data-update PRs,
and CI maintenance across [@shrwnsan](https://github.com/shrwnsan)'s repositories.

**What this account does**

- Runs scheduled GitHub Actions pipelines (marketplace discovery, data
  validation, automated PRs)
- Authors and merges data-update pull requests via a scoped fine-grained PAT
- Nothing else — no human activity, no code review, no social use

**Operating policy**

- All activity is automated and disclosed here; per
  [GitHub ToS §B.3](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service),
  the human owner above is responsible for this account's actions
- Tokens are fine-grained, scoped to a single repository per token, and rotated
- If you see this account acting outside the scope described here, please
  [contact the owner](https://github.com/shrwnsan) or open an issue on the
  affected repository
